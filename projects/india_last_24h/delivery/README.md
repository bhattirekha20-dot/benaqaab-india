# Benaqaab India — 7 October 2026

Start with **Benaqaab_India_07_Oct_2026.mp4**. It is the final export (about 1 minute 58 seconds), not the older HTML draft.

Use title.txt, description.txt and hashtags_and_tags.txt for upload. Thumbnail JPGs are supplied in landscape and vertical formats. headline_captions.srt contains summaries, not verbatim speech.

Read HANDOFF_AND_CORRECTIONS.md for requests, mistakes, fixes, omitted footage and limitations. TECHNICAL_QC.txt records a successful full decode test.

The full ZIP includes the final delivery and project source assets/scripts. Rebuild with Python plus Pillow, NumPy and imageio-ffmpeg; run render_final.py from the project folder. Third-party footage is not included.
