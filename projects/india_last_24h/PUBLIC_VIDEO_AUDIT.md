## Rule

“Publicly available” is not the same as “copyright-free.” Add a video clip only when it is official, openly licensed, supplied by the user, or permission-cleared. Otherwise use a source link, thumbnail, official still, map or recreated data card. Never use an unrelated clip to illustrate a current event.
