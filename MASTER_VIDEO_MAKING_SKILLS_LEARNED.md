## 2. The Unified 7-Pillar Editing Architecture

Every video produced in this style succeeds because of seven interconnected principles that eliminate cognitive friction and maximize psychological retention:

### Pillar 1: The Scale Escalation Ladder
- **Concept:** The human brain cannot comprehend abstract astronomical, financial, or historical scale without relatable rungs on a ladder.
- **The Execution Formula:**
  1. *Rung 1 (Familiar Human Baseline):* Rocket speed (`28,000 km/h`), monthly salary (`₹25,000`), or personal body crease.
  2. *Rung 2 (The Technological Limit):* Traveling at the speed of light (`300,000 km/s`) or India's entire annual budget.
  3. *Rung 3 (The Astronomical Impossibility):* `94.5 Billion Years` to Andromeda, or global sovereign debt.
- **Visual Manifestation:** Large tabular numbers housed in clean dark capsule pills, punctuated by sub-bass impacts and camera shake.

### Pillar 2: The 4.2-Second Shot Cadence (The ASL Contract)
- **Average Shot Length (ASL):** Strictly **3.8 to 4.5 seconds** across the entire video.
- **Why It Works:** It avoids the sensory overload and shallowness of TikTok brainrot (1.5s cuts) while completely destroying the boredom of traditional TV documentaries (7-9s static shots).
- **The 4-Way Rotation Loop:**
  - `Shot A (0-4s):` Presenter talking head (direct eye contact, intimate high-contrast lighting).
  - `Shot B (4-8s):` 3D simulation or celestial animation (cinematic macro perspective).
  - `Shot C (8-12s):` Primary evidence scan (historical newspaper, court order, research paper).
  - `Shot D (12-16s):` Tactile metaphor or pop-culture B-roll (folded paper, movie scene, physical prop).
  - *Repeat loop with micro-punch zoom on Shot A return.*

### Pillar 3: Audio Master Clock & Plosive Syllable Slicing
- **Narration Is King:** Narration is recorded, cleaned, and locked before a single video edit is finalized.
- **Plosive Syllable Cuts:** Edits never occur on random musical beats. Cuts are timed to stressed consonants (`B`, `P`, `K`, `T`, `D`) in the voiceover.
- **Sidechain Ducking Profile:**
  - Music rests at `-22 dBFS` baseline.
  - When voiceover speaks, music ducks by **-8.5 dB** (attack: 15ms, release: 250ms).
  - On visual reveals, music swells by **+6 dB**.
  - On high-stakes curiosity pivots, music drops into **complete silence for 250ms**.

### Pillar 4: The 5 Forensic Motion Primitives
1. **Procedural Yellow Highlighter (`multiply` blend mode):**
   - Color: `#FFE600` or `#FACC15`.
   - Blend: `globalCompositeOperation = 'multiply'`. Dark printed text retains 100% black ink clarity with zero washed-out opacity hazing.
2. **Forensic Optical Loupe (2.2x to 3.0x Magnification):**
   - Circular glass lens with 2px specular border (`rgba(255,255,255,0.25)`), drop shadow (`0 10px 30px rgba(0,0,0,0.5)`), and 1px dashed reticle.
   - Zooms into key dates, signatures, clauses, or microscopic details.
3. **Rolling Tabular Odometer:**
   - Monospace font (`JetBrains Mono` or `DIN Pro Bold`).
   - Digits roll vertically with motion blur and settle using `cubic-bezier(0.05, 0.9, 0.2, 1)`.
4. **Impact Trauma Shake:**
   - 6-to-12 frame damped high-frequency positional shake (`±14px X`, `±8px Y`) synced to sudden shocking statistics.
5. **Callout Pins & Animated Leader Lines:**
   - Target reticle on anatomy/mechanics -> Spring-animated dashed elbow line -> Frosted dark pill with technical label.

### Pillar 5: Color Harmonization & Obsidian Visual Identity (60-30-10 Rule)
- **60% Dominant Base:** Deep chromatic obsidian slate (`#07090E` / `#0A0D14`).
- **30% Structural Secondary:** Frosted glass surfaces (`rgba(15, 20, 32, 0.75)`), dark cards, subtle grid meshes.
- **10% High-Energy Accents:**
  - `Electric Sky (#38BDF8):` Space, tech, theoretical physics, quantum ideas.
  - `Signal Amber / Yellow (#FFE600 / #FBBF24):` Metrics, highlighter ink, optimistic discoveries, money.
  - `Crimson Flame (#F43F5E):` Superstition debunking, physical collapse, warnings, warfare.
  - `Neon Mint (#34D399):` Biology, energy, medical breakthroughs, clean solutions.
- **Volumetric Specular Glow:** Soft rim drop shadows on cards (`drop-shadow(0 0 18px rgba(...))`).
- **Organic SVG Noise Grain:** 3.5% opacity procedural noise overlay to eliminate 8-bit digital banding.

### Pillar 6: Retention Psychology & Open-Loop Stacking
- **The Burning Question Hook (0:00 - 0:05):** Starts with an assumption the viewer takes for granted, then instantly shatters it.
- **Loop Stacking:** Never answer a question without planting the next, higher-stakes mystery.
  - *Example:* "Wormholes exist mathematically! -> But they pinch shut immediately! -> To keep them open we need negative energy! -> Does negative energy exist in nature? -> Yes, the Casimir Effect! -> But how do we harvest it?"
- **Re-engagement Spikes:** Occur every **35 to 45 seconds** (shift from academic theory to tactile demonstration or pop-culture clip).

### Pillar 7: Multi-Source Evidence & The Fact Ledger Contract
- **No Floating Claims:** Every number, rupee figure, year, or scientific paper spoken in the audio is accompanied by its primary source on screen.
- **Primary Source Attribution:** Gazette number, academic journal name, or court petition cited in a discrete monospace tag.

## 4. Code-Rendered Implementation Blueprint (`comp.html`)

For 100% deterministic, 60fps code-rendered video production via Headless Chromium (`viz/hrender.py`), implement these standard reusable primitives:

### 4.1 Procedural Yellow Highlighter (`multiply` mode)
```javascript
function drawHighlighter(ctx, x, y, width, height, progress) {
  if (progress <= 0) return;
  const currentWidth = width * Math.min(1, Math.max(0, progress));
  
  ctx.save();
  ctx.globalCompositeOperation = 'multiply';
  ctx.fillStyle = '#FFE600';
  ctx.beginPath();
  const radius = height * 0.2;
  ctx.roundRect(x, y, currentWidth, height, radius);
  ctx.fill();
  
  // Edge ink bleed
  ctx.fillStyle = 'rgba(250, 204, 21, 0.4)';
  ctx.fillRect(x + currentWidth - 2, y, 4, height);
  ctx.restore();
}
```

### 4.2 Forensic Optical Loupe (2.5x Magnifier)
```javascript
function drawForensicLoupe(ctx, sourceCanvas, cx, cy, radius, zoom) {
  ctx.save();
  
  // Draw drop shadow
  ctx.shadowColor = 'rgba(0, 0, 0, 0.6)';
  ctx.shadowBlur = 24;
  ctx.shadowOffsetY = 10;
  
  // Clip circular lens
  ctx.beginPath();
  ctx.arc(cx, cy, radius, 0, Math.PI * 2);
  ctx.clip();
  ctx.shadowColor = 'transparent'; // reset
  
  // Draw magnified source content
  const sw = (radius * 2) / zoom;
  const sh = (radius * 2) / zoom;
  const sx = cx - sw / 2;
  const sy = cy - sh / 2;
  ctx.drawImage(sourceCanvas, sx, sy, sw, sh, cx - radius, cy - radius, radius * 2, radius * 2);
  
  // Draw glass bezel & crosshairs
  ctx.strokeStyle = 'rgba(255, 255, 255, 0.4)';
  ctx.lineWidth = 3;
  ctx.stroke();
  
  // Crosshairs
  ctx.strokeStyle = 'rgba(56, 189, 248, 0.6)';
  ctx.lineWidth = 1;
  ctx.setLineDash([4, 4]);
  ctx.beginPath();
  ctx.moveTo(cx - radius * 0.4, cy); ctx.lineTo(cx + radius * 0.4, cy);
  ctx.moveTo(cx, cy - radius * 0.4); ctx.lineTo(cx, cy + radius * 0.4);
  ctx.stroke();
  
  ctx.restore();
}
```

### 4.3 Tabular Rolling Odometer
```javascript
function drawRollingOdometer(ctx, targetNum, currentProgress, x, y, prefix = '', suffix = '') {
  const currentVal = Math.round(targetNum * easeOutCubic(currentProgress));
  const text = `${prefix}${currentVal.toLocaleString('en-IN')}${suffix}`;
  
  ctx.save();
  ctx.font = '700 48px "JetBrains Mono", monospace';
  ctx.fillStyle = '#FFFFFF';
  ctx.textAlign = 'center';
  ctx.textBaseline = 'middle';
  
  // Draw background dark pill
  const metrics = ctx.measureText(text);
  const pw = metrics.width + 40;
  const ph = 70;
  ctx.fillStyle = 'rgba(10, 13, 20, 0.85)';
  ctx.strokeStyle = 'rgba(255, 255, 255, 0.12)';
  ctx.lineWidth = 1;
  ctx.beginPath();
  ctx.roundRect(x - pw/2, y - ph/2, pw, ph, 16);
  ctx.fill();
  ctx.stroke();
  
  // Draw tabular text with golden highlight
  ctx.fillStyle = '#FFE600';
  ctx.fillText(text, x, y);
  ctx.restore();
}

function easeOutCubic(x) {
  return 1 - Math.pow(1 - x, 3);
}
```

### 4.4 Camera Trauma Screen Shake
```javascript
function getCameraShake(trauma, t) {
  if (trauma <= 0) return { x: 0, y: 0 };
  const frequency = 45; // Hz
  const maxOffset = 14; // pixels
  const decay = Math.max(0, trauma);
  const shakeX = (Math.sin(t * frequency) * maxOffset) * (decay * decay);
  const shakeY = (Math.cos(t * frequency * 1.3) * maxOffset * 0.6) * (decay * decay);
  return { x: shakeX, y: shakeY };
}
```

## 6. Pre-Production QA Checklist for New Videos

Before writing any `comp.html` or rendering an MP4:
- [ ] **Gate 0 Confirmed:** User explicitly verified Format (16:9 Long-Form vs 9:16 Shorts) and Target Duration.
- [ ] **Master Clock Locked:** Voiceover audio recorded, processed (-14 LUFS), and mapped word-by-word.
- [ ] **Visual Density Standard:**
  - Long-Form (16:9): Minimum **10 curated visual assets per minute** (ASL ≤ 4.5s).
  - Shorts (9:16): Minimum **30 visual cuts per Short** (1 cut every 1.5 - 2.0s).
- [ ] **Evidence Proof Bound:** Every spoken figure or claim has its primary document or verified real media asset attached.
- [ ] **Zero AI Slop:** No untextured cards, no flat purple gradients, no TikTok karaoke word-by-word clutter.
- [ ] **Pure Canvas Render Isolation:** Render mode hides all UI controls, bars, and headers.
